Versioned together. Adopted at each company’s own pace.

0:50 · Oscar · Opening 7/11

We call this proposed starting point an InnerSource landing zone. The term is our framing for this talk, not an official InnerSource pattern. Start with a common foundation: identity, network and infrastructure. [Step 1] Add operational capabilities such as delivery, observability and security controls, then the paths teams use to build or request services. We are sharing how those capabilities fit together, with versions, documentation and maintainers. [Step 2] Each company can run its own instance and adopt a chosen version. [Step 3] Improvements that help other adopters return through reviewed pull requests. The proposal is a shared foundation that remains extensible. It gives common decisions a place to evolve together without removing each company's specific operating context.
