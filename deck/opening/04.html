Autonomy is necessary. Repeating every common decision is costly.

0:40 · Oscar · Opening 4/11

Our context is a group of companies. Each has its own priorities, teams and operating environment. [Step 1] Yet a familiar request arrives in each place: we need to build and operate a service. [Step 2] Behind that request sit many of the same needs: identity, networking, delivery, security and observability. Local context matters, so autonomy is necessary. But autonomy can also leave teams solving common foundational problems separately. These companies are illustrative; this is not a ranking or a measured comparison. The question is where independent decisions add value, and where a shared starting point could help.
